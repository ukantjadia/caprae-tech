## The one-line brief

A site for people who buy companies, built by the team that builds the tools
they use, which proves its own claim by existing.

The site is the portfolio. If a buyer looks at this page and thinks "these
people can build," the page has done its job. Every 3D element and every scroll
transition is in service of that, or it is decoration and gets cut.

## Read this before designing anything

`01-direction.md` opens with a conflict between the stated design goal and the
stated UX rules. It is not resolved yet. Designing before it is settled means
building twice.

Source of truth for the Caprae technical services website. Everything the site says
should trace back to a file in here.

| File | Contains |

## Status legend

Every claim in these files is tagged:

- **[VERIFIED]** Found on capraecapital.com, capraecapitalpartners.com, or a named
  public source. Safe to put on the website.
- **[STATED]** Told to us by the project owner. Not yet checked against a public
  source. Safe to use, but confirm numbers before publishing.
- **[OPEN]** Unknown. Listed in `05-open-questions.md`.

Do not put an **[OPEN]** item on the website. Do not invent a number.
